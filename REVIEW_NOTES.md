# Review build — story-first version

This build changes the storytelling structure from **one month = one block of text + all photos** to **one memory = one scene**.

## Main flow

- Intro: “Một câu chuyện về em”
- Year opener
- Story moments such as 08.03, 10.03, 18–20.03, 26.03
- Matching photos/videos directly below each story moment
- Reflection: “Và rồi cứ như vậy…”
- Birthday preface
- Happy Birthday letter
- Future reveal

## Files to review/edit

- `data/story.js`: all story wording and media-day grouping
- `js/app.js`: story-moment rendering
- `css/scenes.css`: story scene layout
- `css/responsive.css`: 13-inch laptop / iPad sizing
- `notes/story-reference.md`: the approved story direction used as the writing reference

## Media grouping

All 113 dated media items are explicitly assigned to one story moment. No dated media item is duplicated or left out in this review build.
